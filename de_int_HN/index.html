Desenvolvimento de interfaces

As 10 heurísticas de usabilidade de Jakob Nielsen

Um guia de referência sobre os princípios que orientam interfaces fáceis de entender e usar, revisado com foco em design thinking e nas diretrizes de acessibilidade WCAG.

Heurísticas Relatório Sobre mim

Por que essas heurísticas importam

Em 1994, Jakob Nielsen reuniu dez princípios amplamente aplicáveis para avaliar a usabilidade de qualquer interface. Eles não são regras rígidas, mas lentes: perguntas que um designer pode fazer sobre o próprio trabalho para encontrar pontos de atrito antes que o usuário os encontre.

01

Visibilidade do status do sistema

O sistema deve manter o usuário informado sobre o que está acontecendo, com retorno em tempo razoável. Uma barra de progresso, uma confirmação de envio ou um indicador de carregamento evitam que a pessoa se pergunte se algo deu errado.

02

Correspondência entre o sistema e o mundo real

A interface deve usar palavras e conceitos familiares ao usuário, em vez de termos orientados ao sistema.

03

Controle e liberdade do usuário

O sistema deve permitir que o usuário controle o processo e reverta ações.

04

Consistência e padrões

Elementos semelhantes devem funcionar e aparecer de forma idêntica em todo o sistema.

05

Prevenção de erros

A interface deve ser projetada para evitar que os usuários cometam erros, ou devem fornecer uma forma fácil de reverter ações.

06

Reconhecimento em vez de memorização

Os usuários devem ser capazes de reconhecer elementos do sistema em vez de lembrar informações.

07

Flexibilidade e eficiência de uso

O sistema deve atender tanto usuários iniciantes quanto experientes, oferecendo maneiras mais rápidas de realizar tarefas.

08

Design estético e minimalista

A interface deve ser visualmente atraente e evitar elementos desnecessários.

09

Ajudar os usuários a reconhecer, diagnosticar e recuperar erros

Quando ocorrem erros, o sistema deve explicá-los claramente e indicar como corrigi-los.

10

Ajuda e documentação

O sistema deve disponibilizar informações e instruções para orientar o usuário quando necessário.

Relatório de aplicação

Para a realização dessa página web, foram utilizados os conceitos e práticas adquiridas em HTML e CSS nos estudos de programação. Em HTML, foi implementada a nav bar (barra de navegação), auxiliada por meio do website W3schools. O design da página, bem como as dimensões e cores, foram definidas com base em protótipos prévios realizados pelo Canva e pelo website Lovable. O conteúdo do site, "As 10 heurísticas de usabilidade de Jakob Nielsen", foi adquirido em aulas teóricas e artigos acadêmicos na internet, de onde foram tiradas as frases resumidas para explicar cada conceito.
