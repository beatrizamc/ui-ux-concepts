Diretrizes de Acessibilidade para Conteúdo Web

Padrão internacional que orienta como tornar a web acessível para todos, incluindo as pessoas com deficiências visuais, motoras, auditivas ou cognitivas.

  • Princípios
  • Critérios
Diretrizes Desenvolvidas pelo W3C (World Wide Web Consortium), elas funcionam como um manual de boas práticas para designers, desenvolvedores front-end e criadores de conteúdo online. Essas são algumas das práticas mais comuns:
  1. Perceptível: as informações e os componentes da interface devem ser apresentados aos usuários de formas que eles consigam perceber com seus sentidos, como textos alternativos para imagens e legendas para vídeos.
  2. Operável: a interface não pode exigir ações que o usuário não consiga realizar. Toda navegação deve ser funcional e não pode conter elementos confusos.
  3. Compreensível: a informação e operação da interface devem ser claras e previsíveis. Mensagens de erro devem explicar o que está acontecendo e o que o usuário deve corrigir.
  4. Robusto: o conteúdo deve ser maduro o sufuciente para ser interpretado por uma ampla variedade de tecnologias assistivas. O código em HTML deve ser organizado para navegadores e leitores de tela conseguirem ler páginas sem falha, por exemplo.
Critérios Necessários Cada critério é uma verificação de conformidade. Você pode conferir:
  • Contraste mínimo: textos corridos precisam de um contraste mínimo de 4.5:1 com fundo 3:1 para textos grandes.
  • Redimensionar texto: o texto deve ampliar até 200% sem perda de conteúdo ou de funcionalidade.
  • Foco visível: todo elemento operável pelo teclado mostra um indicador de foco que orienta, em vez de apenas jogar informações.
